# Using Conducto

These guides move from one local function call to a separately hosted,
model-backed agent.

1. [Create one local agent](./first-local-agent.md)
2. [Connect an agent to Ollama](./ollama-agent.md)
3. [Connect two local agents](./two-agent-workflow.md)
4. [Host an agent for another process](./host-an-agent.md)

Start locally even if the final deployment will use containers or a hosted
platform. Local execution proves the capability contract without adding
network, identity, or deployment variables.

For repository development and package verification, use the
[SDK quick start](../quickstart.md).
